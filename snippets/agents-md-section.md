## Start here: area guides

Each area has a short guide with its main ideas and a file map; agents load it when they work in that folder.
Begin with `docs/agent-guides/README.md` (Optio's main ideas and the index), then the area's guide:
`apps/api/AGENTS.md`, `apps/api/src/services/AGENTS.md`, `apps/web/AGENTS.md`, `apps/cli/AGENTS.md`,
`packages/<name>/AGENTS.md`, `helm/AGENTS.md`, `images/AGENTS.md`, `scripts/AGENTS.md`.
Prefer them to reading this file end to end. `bash scripts/check-agent-guides.sh` keeps them in step with the tree.
